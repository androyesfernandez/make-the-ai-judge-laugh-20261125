An entry for the make.fun competition **Make the AI Judge Laugh**: one line
about office life, written to make the judge laugh.

The program (`main.py`, Python 3, standard library only) writes a single
167-character joke to `/output/entry.txt`:

> My manager opened my review by saying I was doing great, then spent forty minutes explaining why great wasn't good enough for the raise I had already spent in my head.

Run it with `python3 main.py`.
